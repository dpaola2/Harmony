# Source geometry

Waveshare 29318: vendor STEP originally stored with the Mark-6 hardware study. Product documentation: https://www.waveshare.com/wiki/3.5inch_Capacitive_Touch_LCD . `waveshare-vendor-original.step` is preserved without modification. The transformed version is an assembly reference, not a redesigned display.

Adafruit MPR121: https://github.com/adafruit/Adafruit-MPR121-PCB . The Eagle QT board establishes the footprint; its supplied README and license are included here. Actual owned-board revision still requires comparison.

Carrier dimensions come from Harmony2 `hardware/mark-7/carrier-rev-a/mechanical/carrier.step`. The 19.77 mm assembled height comes from Dave's prior measurement recorded in the Mark-7 build notes. The 20.27 mm envelope adds 0.5 mm clearance.
