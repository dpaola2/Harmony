# Harmony R1 design package

Start with `README.md` in this directory for printing and assembly. The project recommendation is `../../docs/Harmony-2026-reassessment.md`; detailed architecture and acceptance criteria are next to it. Reference electronics and their license are under `../../hardware/tangara-reference/`.

This package contains all eight printed enclosure components plus two fit coupons, editable sources, and reference electronics. It is a digital fit prototype. No physical printing, hardware bring-up, or battery/runtime testing has occurred. No new Harmony firmware or original PCB was implemented.
